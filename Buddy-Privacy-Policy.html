Buddy 隐私政策

Buddy（以下简称“本应用”）重视您的隐私和个人信息安全。本政策说明您使用本应用时， 我们如何处理、存储和保护相关信息，以及您可以如何管理这些信息。

请您特别注意：当您使用 AI 对话、摘要或长期记忆蒸馏功能时，完成请求所必需的对话内容及上下文 会发送至您当前选择的 AI 服务提供方。不同提供方将按照各自的隐私政策处理收到的数据。

一、适用范围

本政策适用于 Buddy 客户端及其提供的 AI 对话、Agent 配置、伙伴设置、对话记录、摘要、长期记忆等功能。 对于您主动选择或配置的第三方 AI 服务，其独立的数据处理行为不由本政策完全约束，您还应阅读相应第三方的隐私政策。

二、我们处理的信息

根据您实际使用的功能，本应用可能处理以下信息：

  • 对话内容：您发送的消息、AI 返回的消息、消息角色、创建时间及当前伙伴标识；
  • 对话摘要：为保持长对话连贯性而生成的滚动摘要，以及摘要覆盖范围和更新时间；
  • 长期记忆：从对话中提取或由您管理的事实、偏好、经历、目标、特征和其他记忆，以及相关置信度、重要性、状态和来源关系；
  • 伙伴与应用设置：当前伙伴、伙伴相关设置、界面状态、协议同意状态和其他本地偏好；
  • Agent 配置：您创建的配置名称、服务提供方、接口地址、模型名称、API Key、生成参数及自定义请求头；
  • 请求信息：向 AI 服务发起请求时所需的模型参数、系统提示词、相关对话上下文、摘要和被召回的长期记忆；
  • 网络连接信息：当设备访问第三方 AI 接口时，第三方服务通常会自然接收到 IP 地址、请求时间、网络协议和基础客户端信息。

三、我们如何使用信息

我们处理上述信息主要用于：

  • 保存并展示您的对话，使您能够继续历史上下文；
  • 向您选择的 AI 服务发送请求并展示回复；
  • 生成对话摘要，降低长对话的上下文长度；
  • 提取、合并、检索和展示长期记忆，提升伙伴回复的连贯性与个性化程度；
  • 保存并切换您创建的 Agent、模型和伙伴配置；
  • 响应您的删除、修改、启用或其他应用内操作；
  • 保障基本功能运行、排查本地错误并改进使用体验。

我们不会将您的对话或长期记忆用于广告画像，也不会出售您的个人信息。

四、AI 服务与第三方数据传输

本应用支持 DeepSeek、智谱 AI 以及您自行配置的 OpenAI 协议兼容服务等 Agent。 当您启用某个配置并发起 AI 请求时，本应用会从您的设备向对应接口发送完成请求所必需的数据，可能包括：

  • 当前消息及必要的历史对话；
  • 系统提示词、伙伴设定和请求参数；
  • 为维持上下文而使用的对话摘要；
  • 与当前对话相关、被召回的长期记忆；
  • 您配置的 API Key、自定义请求头、模型名称及接口地址。

数据的接收方由您启用的 Agent 配置决定。第三方可能基于安全、计费、合规或服务改进目的记录请求， 具体保存期限和使用方式以该服务提供方的条款和隐私政策为准。请勿选择您不信任的接口地址， 也请勿在对话中提交非必要的高度敏感信息。

五、API Key 与 Agent 配置

您输入的 API Key 和 Agent 配置会保存在本应用的本地数据库中，并在发起请求时用于目标服务的身份验证。 当前配置下，这些信息并非由我们托管在独立的云端账号系统中。

  • API Key 属于敏感凭证，请仅在可信设备上配置并妥善保管；
  • 如设备被他人控制、系统备份被恢复或本地数据遭到未经授权访问，凭证可能面临泄露风险；
  • 您可以在 Agent 配置页面删除相应配置；如怀疑密钥泄露，请同时前往服务提供方控制台撤销或轮换密钥；
  • 自定义接口地址可能由未知第三方运营，请您在保存和启用前自行确认其可信度。

六、对话摘要与长期记忆

长期记忆功能会使用 AI 模型分析尚未蒸馏的对话，提取事实、偏好、经历、目标、特征或其他信息， 并可能将新结果与已有记忆一并发送给当前 AI 服务进行合并。该过程可能产生错误、遗漏或不准确推断。

  • 长期记忆主要保存在设备本地，用于后续对话召回；
  • 记忆蒸馏或合并时，相关原始消息和已有记忆可能被发送至当前选择的 AI 服务；
  • 您可以在记忆页面查看、触发更新或合并，并删除不希望保留的记忆；
  • 请定期核对重要记忆，不应将 AI 自动提取结果视为完全准确的个人档案。

七、本地存储与系统备份

对话、摘要、长期记忆、伙伴数据和 Agent 配置等信息主要存储在您的设备本地；协议同意状态、当前 Agent、 当前伙伴及部分界面偏好也会保存在本地。我们当前不提供独立的 Buddy 云端账号同步服务。

操作系统可能根据您的设备设置、账号设置和平台机制对应用数据进行备份或迁移。 此类系统级备份由相应平台提供方管理，您可以在设备系统设置中管理相关选项。

八、系统权限

当前版本未声明定位、相机、麦克风、蓝牙、通讯录、相册等敏感系统权限。 本应用会使用网络连接访问您选择的 AI 服务。若未来新增功能确需申请敏感权限， 我们会在调用前通过系统授权界面说明用途，并根据实际变化更新本政策。

九、数据保留与删除

本地数据通常会保留至您主动删除相关内容、清除应用数据或卸载本应用。您可以通过应用内现有管理入口 删除 Agent 配置和长期记忆；其他本地数据可通过设备系统的“清除应用数据”或卸载操作一并移除。

清除本地数据不会自动删除第三方 AI 服务此前已经接收或保存的数据。如需删除第三方保存的数据， 请按照对应服务提供方提供的渠道提交请求。操作系统备份中的副本可能会按照平台自身周期继续保留一段时间。

十、信息共享、转让与公开披露

除以下情况外，我们不会主动向其他主体共享、转让或公开披露您的个人信息：

  • 为完成您主动发起的 AI 请求，向您选择的服务提供方发送必要数据；
  • 已获得您的明确同意；
  • 为履行法定义务，或响应有权机关依法提出的要求；
  • 为保护您、其他用户或公众的生命、财产及其他重大合法权益且符合法律规定。

十一、安全保护

我们会采取与当前应用形态相适应的措施减少未经授权访问、泄露、篡改或丢失的风险。 但互联网传输、设备本地存储和第三方接口均无法保证绝对安全。建议您为设备设置可靠的锁屏验证， 不要共享 API Key，并及时安装可信来源的应用更新。

十二、您的权利与选择

在适用法律规定的范围内，您可以：

  • 在应用内查看和管理 Agent 配置、长期记忆及其他可见数据；
  • 删除不再需要的配置或长期记忆；
  • 停止使用特定 Agent，避免继续向该服务发送新请求；
  • 通过清除应用数据或卸载应用删除设备上的全部应用数据；
  • 通过本政策列明的联系方式，就信息处理提出询问、意见或请求。

十三、未成年人保护

未成年人应在监护人的同意和指导下使用本应用。监护人应帮助未成年人理解 AI 对话可能涉及的数据传输， 避免其输入身份凭证、联系方式、精确住址、学校信息或其他不必要的敏感信息。 如监护人认为未成年人的信息被不当处理，请联系我们。

十四、政策更新

我们可能因功能、数据处理方式、第三方服务或法律法规变化更新本政策。发生重要变化时， 我们会通过应用内页面、弹窗或其他合理方式提示您。更新后的政策自标明的生效日期起生效。
